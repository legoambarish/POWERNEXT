# Competition materials

This folder keeps the supplied problem material and the working documents used to define the Track 1 release. These files are evidence inputs, not interchangeable specifications. Where statements conflict, the dated CPRI clarification and the source classification in `powernext/physics/SOURCE_REGISTER.json` control how the application treats them.
