# Two-versus-three waveform report

The current deliverable is the bounded five-case preliminary study. Its methods, five actual Physics comparisons, post-selection fixed-N/charge replays, nominal double-exponential references, absolute and crest-normalized common-grid errors, exact artifact links, and scope limits are documented in [`TWO_VS_THREE_PRELIMINARY.md`](TWO_VS_THREE_PRELIMINARY.md). Each fixed-N/charge row replays the network selected at legal optimized charge; it is not a fixed-charge optimum.

The current evidence is [`evidence/two_vs_three/preliminary_v4`](../evidence/two_vs_three/preliminary_v4). It contains three cpri LI and two cpri SI cases, selected before ≤3 simulation, with exact ≤2 baseline replays and bounded ≤3 samples. The v4 replay uses the hardened benchmark identity guard and includes [`rerun_validation.json`](../evidence/two_vs_three/preliminary_v4/rerun_validation.json), which confirms equality of the selected scientific metrics, configurations, and recipe trees with v3; only the explicit post-selection replay label changed. A full ≤3 campaign remains deferred; this report does not present the preliminary sample as a global optimum, hardware validation, or an ML result.
